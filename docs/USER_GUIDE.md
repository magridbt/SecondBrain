## 1. O que é o SecondBrain?

O SecondBrain de Sri Amma Bhagavan é uma plataforma espiritual de inteligência artificial que permite acessar, explorar e produzir conteúdo baseado nos ensinamentos de Sri Amma Bhagavan — com precisão e fidelidade ao ensinamento original.

O sistema está conectado a uma base de conhecimento com centenas de documentos: darsháns, programas, transmissões, textos e vídeos do Bhagavan e de fontes autorizadas.

**O que você pode fazer:**
- Conversar com a base de ensinamentos e receber respostas citando fontes reais
- Interagir com o Clone Cognitivo — IA construída a partir do DNA Mental de Sri Amma Bhagavan
- Buscar ensinamentos por tema e ver os resultados mais relevantes
- Gerar mensagens diárias para divulgação nas redes sociais
- Produzir conteúdo para cursos específicos
- Criar posts para 8 redes sociais diferentes
- Gerar textos de Milagres

## 3. SecondBrain — Chat RAG

**Acesso:** Sidebar → SecondBrain (ícone de chat)

O SecondBrain é um chat que responde exclusivamente com base nos documentos indexados na base de conhecimento. Cada resposta cita as fontes utilizadas.

### Como usar

1. Digite sua pergunta sobre os ensinamentos na caixa de texto
2. Pressione Enter ou clique em Enviar
3. A resposta aparece em tempo real (streaming)
4. Ao final, as **fontes citadas** são exibidas com nome do documento, data e link YouTube quando disponível

### Comportamento importante

- Se a pergunta não tiver ensinamentos relevantes na base, o sistema informa que não encontrou — **não inventa respostas**
- O chat mantém o contexto das últimas mensagens da conversa (memória conversacional)
- Histórico de conversas salvo automaticamente

### Dicas

- Perguntas mais específicas trazem resultados melhores
- Se não encontrou resposta, tente reformular com outras palavras
- Use o botão de **nova conversa** para iniciar um contexto limpo

## 4. Clone Cognitivo

**Acesso:** Sidebar → Clone Cognitivo (ícone roxo)

O Clone Cognitivo é uma IA construída a partir do DNA Mental de Sri Amma Bhagavan — seus padrões de voz, pensamento, linguagem e comportamento mapeados em centenas de horas de ensinamentos.

### Diferença do SecondBrain

| | SecondBrain | Clone Cognitivo |
|--|-------------|-----------------|
| Busca na base | Sim | Sim |
| Responde sem contexto | Não | **Sim** |
| Estilo de resposta | Informativo, cita fontes | Voz e presença do Bhagavan |
| Recusa responder | Quando não há contexto | Nunca |

### Aviso de transparência

O banner **"DNA Mental • IA"** no topo indica que as respostas são geradas por inteligência artificial com base no DNA dos ensinamentos — não são palavras literais do Bhagavan, mas emergem do padrão profundo do seu ensinamento.

### Como usar

Igual ao SecondBrain — digite sua pergunta e receba a resposta em streaming. O Clone responde na voz, presença e estilo do Bhagavan, incluindo perguntas que apontam de volta ao perguntador, humor gentil, clareza e compaixão.

## 5. Explorar

**Acesso:** Sidebar → Explorar

Busca semântica pura nos ensinamentos — sem geração de texto por IA. Ideal para encontrar documentos e trechos específicos.

### Como usar

1. Digite um tema, palavra ou frase
2. O sistema retorna os trechos mais semanticamente próximos da sua busca
3. Cada resultado mostra: fonte, documento, data, % de relevância e trecho do conteúdo

### Quando usar

- Quando quiser ver **onde** um tema aparece nos ensinamentos, sem interpretação da IA
- Para navegar pela base de conhecimento e descobrir documentos relevantes
- Pesquisa antes de gerar conteúdo

## 6. Mensagem Diária

**Acesso:** Sidebar → Mensagem Diária

Gera mensagens inspiradoras baseadas nos ensinamentos para divulgar em grupos, redes sociais ou comunidades.

### Como usar

1. Informe um **tema** (ex: "graça divina", "impotência", "despertar")
2. Escolha o **idioma** (Português, Inglês ou Espanhol)
3. Escolha o **provider** de IA (Claude, ChatGPT ou Gemini) — se configurado
4. Clique em **Gerar Mensagem**
5. A mensagem aparece em streaming
6. Copie ou salve para usar

### Prompts Customizados

Em **Mensagem Diária → Prompts** você pode criar seus próprios prompts para definir o estilo, tom e formato das mensagens geradas. Marque um prompt como **padrão** para que seja usado automaticamente.

### Configurações de IA

Em **Mensagem Diária → Configurações** você pode configurar suas próprias chaves de API para usar modelos específicos.

## 10. Perguntas Frequentes

**Por que o SecondBrain às vezes não encontra resposta?**
A base de conhecimento contém documentos específicos. Se o tema não foi abordado nos documentos indexados, o sistema informa honestamente em vez de inventar. Tente reformular a pergunta ou use o Clone Cognitivo para respostas a partir do DNA Mental.

**Qual a diferença entre SecondBrain e Clone Cognitivo?**
O SecondBrain é um pesquisador fiel — só responde com o que está nos documentos e cita as fontes. O Clone Cognitivo é uma presença — responde sempre, com a voz e padrão de consciência do Bhagavan, com ou sem documentos de contexto.

**As respostas do Clone são palavras literais do Bhagavan?**
Não. São geradas por IA a partir do DNA Mental mapeado dos ensinamentos. O badge "DNA Mental • IA" está sempre visível para indicar isso.

**Posso usar o conteúdo gerado diretamente nas redes sociais?**
Sim, o conteúdo é gerado para uso direto. Recomendamos sempre revisar antes de publicar para garantir alinhamento com o contexto específico da sua comunidade.

**Como aumentar meu limite de mensagens?**
Os limites são definidos pelo administrador. Entre em contato com o admin da plataforma para solicitar ajuste.

**Não consigo fazer login. O que fazer?**
- Verifique se o email está correto
- Use "Esqueci minha senha" para resetar
- Se usou um convite, certifique-se de ter concluído o cadastro pelo link recebido
- Em último caso, contate o administrador
