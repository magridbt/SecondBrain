🔧 SE ALGO FALHAR

Servidor não responde?
  $ curl http://localhost:3002
  Se erro, reinicie:
  $ pkill -f "next dev"
  $ cd "/Users/lei/Documents/Magrid/CheckTools/secondbrain/Sri Amma Bhagavan"
  $ npm run dev -- -p 3002

Busca retorna "No results"?
  → Verifique logs para "VECTOR_SEARCH_ERROR" ou "NO_VECTOR_RESULTS"
  → Se vir erro, há problema com embedding
  → Se vir "NO_VECTOR_RESULTS", tente documento diferente

Similarity scores são 0.0 ou 1.0?
  → Indica que fix NÃO foi aplicado
  → Verifique se servidor foi reiniciado após changes
  → Verifique /tmp/nextjs-server.log para erros
